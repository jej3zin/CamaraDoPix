# Câmera do Pix

Frontend demonstrativo feito com React, Vite e Ionic React.

## Rodar localmente
```bash
npm install
npm run dev
```

## Build de produção
```bash
npm run build
npm run preview
```

## Incluído
- Homepage responsiva em preto, branco e azul escuro.
- Hero com imagem de fundo.
- Seções explicativas, categorias, exemplos de donates e contribuição.
- Busca em modal com filtros por Textos, Spans e Números.
- Pesquisa por nome, mensagem, valor, categoria/tag e identificador.
- Links para o repositório e para abrir issues/sugestões.

Os 12 donates são dados de demonstração em `src/App.jsx`. A pesquisa funciona no frontend; ainda não há backend conectado.
